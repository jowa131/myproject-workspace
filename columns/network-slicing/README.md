# 네트워크 슬라이싱 칼럼 프로젝트

이 폴더는 네트워크 슬라이싱 칼럼 연재를 관리하기 위한 Obsidian-friendly 작업 공간입니다.

정본 위치: `C:\MyProject\columns\network-slicing`

작성 완료된 칼럼은 별도 승인/편입 작업을 통해 `C:\MyProject\yulchive-astro` 정적 블로그로 전달되어 포스팅됩니다. 이 폴더는 조사, 원고, 슬라이드, 표를 관리하는 upstream 작업 공간이며, `yulchive-astro` 콘텐츠 컬렉션에 직접 게시된 상태는 아닙니다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `00_admin` | 연재 로드맵, 작업 관리, 메모 |
| `01_sources` | 표준, 벤더, 사업자 발표, 참고자료 정리 |
| `02_notes` | 조사 메모, 아이디어, 시험 경험 정리 |
| `03_drafts` | 칼럼 원고 초안 |
| `04_slides` | Obsidian Slides 자료 |
| `05_tables` | 벤더 비교표, 사례 분류표 |
| `assets` | 이미지, 도식, 캡처 |

## 작성 원칙

- 확인된 자료와 추정은 분리한다.
- `상용 서비스`, `상용망 trial`, `PoC/lab demo`, `제품 capability`를 구분한다.
- 벤더 비교는 우열보다 구현 철학 중심으로 쓴다.
- 시험 경험은 규격/로그/관찰 결과와 연결한다.
