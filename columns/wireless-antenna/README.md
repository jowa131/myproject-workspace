# 무선 통신과 안테나 칼럼 프로젝트

이 폴더는 무선 통신과 안테나 원리를 비전공 독자에게 설명하는 칼럼 연재 작업 공간입니다.

정본 위치: `C:\MyProject\columns\wireless-antenna`

작성 완료된 칼럼은 별도 승인/편입 작업을 통해 `C:\MyProject\yulchive-astro` 정적 블로그로 전달되어 포스팅됩니다. 이 폴더는 기획, 원고, 도식, 메모를 관리하는 upstream 작업 공간이며, 아직 `yulchive-astro` 콘텐츠 컬렉션에 직접 게시된 상태는 아닙니다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `00_admin` | 연재 로드맵, 작업 관리 |
| `01_sources` | 참고자료와 검증 메모 |
| `02_notes` | 아이디어, 설명 원칙, 보조 메모 |
| `03_drafts` | 칼럼 원고 초안 |
| `04_slides` | Obsidian Slides 자료 |
| `05_tables` | 비교표, 용어표 |
| `assets` | 이미지, 도식, 캡처 |

## 작성 원칙

- 한 편에 하나의 중심 질문만 둔다.
- 정보 전달, 안테나 물리, 휴대폰 안테나, 지향성 문제를 한 글에 과도하게 섞지 않는다.
- 비유는 먼저 이해를 돕고, 바로 뒤에서 한계를 밝혀 오해를 줄인다.
- 그림은 바로 옆 문단의 이해를 돕는 경우에만 넣는다.
- 확인된 물리 원리와 단순화한 설명을 구분한다.
