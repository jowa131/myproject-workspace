# 1화 시작 전 인터뷰 질문지

이 질문지는 1화를 인스타용 4컷 웹툰으로 만들기 전에 필요한 정보를 모으기 위한 것입니다. 답변에는 실제 실명, 회사명, 고객명, 프로젝트명, 실제 발생일, 구체적 수치, 내부 도구명, 비밀정보를 쓰지 않습니다. 필요하면 `큰 조직`, `외부 요청자`, `새 역할`, `금요일 오후 같은 시간대`처럼 흐린 표현으로 답합니다.

## 0. 답변 안전 규칙

먼저 아래 질문에 답합니다.

1. 이 에피소드를 공개 후보로 만들고 싶으신가요, 아니면 비공개 초안으로만 두고 싶으신가요?
2. 원본 사건을 아는 사람이 봤을 때 특정 조직이나 사람이 떠오를 위험은 낮음, 중간, 높음 중 어디에 가깝습니까?
3. 절대 드러나면 안 되는 범주는 무엇입니까? 인물, 조직, 고객, 프로젝트, 일정, 금액, 보안, 계약, 인사 중 골라 주세요.
4. 답변에서 제가 다시 흐려야 할 표현이 있다면 어떤 종류입니까?

## 1. 1화의 위치

1. 1화는 독자를 어디에서 시작하게 할까요?
   - 글로벌 통신장비사처럼 보이는 큰 무대의 현재
   - 작은 회사 회상으로 들어가기 직전의 현재
   - 이상한 상사 또는 갑을 관계 압박이 바로 보이는 장면
   - 과도한 업무량이 바로 보이는 장면
2. 1화에서 독자가 바로 느껴야 할 감정은 무엇입니까?
   - 당황
   - 억울함
   - 웃픈 체념
   - 이상함
   - 기대와 불안
3. 1화의 역할은 무엇에 가까워야 합니까?
   - 강한 어그로
   - 주인공 소개
   - 세계관 소개
   - 빌런 또는 압박 구조 소개
   - 다음 화 회상으로 넘기는 장치

## 2. 원본 감정만 말하기

실제 사건 설명 대신 감정과 구조만 답합니다.

1. 그때 가장 크게 남은 감정은 무엇이었습니까?
2. 지금 생각하면 웃긴 지점은 무엇입니까?
3. 그때는 힘들었지만 웹툰으로 바꾸면 공감될 지점은 무엇입니까?
4. 독자가 댓글로 `이거 내 얘기다`라고 할 만한 보편적 순간은 무엇입니까?

## 3. 각색된 상황

실제 회사나 프로젝트를 말하지 말고, 아래처럼 각색된 정보만 줍니다.

1. 장소는 어디처럼 보이면 좋습니까?
   - 회의실
   - 사무실 자리
   - 메신저 화면
   - 문서 검토 화면
   - 퇴근 직전 자리
2. 사건을 시작하는 힘은 무엇입니까?
   - 이상한 상사의 한마디
   - 외부 요청자의 압박
   - 갑자기 늘어난 업무량
   - 애매한 메일 또는 메신저
   - 회의에서 정해진 듯 정해지지 않은 일
3. 이 상황을 한 문장으로 흐리게 말하면 어떻게 됩니까?
   - 예: `큰 조직에 왔는데, 더 체계적일 줄 알았던 일이 이상한 방식으로 몰려왔다.`

## 4. 등장 역할

실제 인물이 아니라 역할로만 답합니다.

1. 1화에 필요한 인물 역할은 누구입니까?
   - 기록자
   - 급한 요청자
   - 이상한 관리자
   - 침착한 정리자
   - 외부 압박자
   - 말없이 모든 것을 아는 동료
2. 주인공은 어떤 상태로 보여야 합니까?
   - 적응하려는 신입 느낌
   - 이미 지쳤지만 버티는 사람
   - 잘해보려는 사람
   - 뭔가 이상함을 감지한 사람
3. 빌런성은 개인에게 둘까요, 아니면 시스템/일정/요청/문서에 분산할까요?

## 5. 4컷 뼈대

짧게만 답해도 됩니다.

| 컷 | 제가 묻는 질문 | 사용자 답변 |
| --- | --- | --- |
| 1컷 훅 | 첫 장면에서 독자가 바로 봐야 할 이상한 점은 무엇입니까? |  |
| 2컷 꼬임 | 그 이상한 점이 어떻게 더 꼬입니까? |  |
| 3컷 폭발 | 가장 웃기거나 어이없는 순간은 무엇입니까? |  |

## 6. 대사 재료

실제 말투를 그대로 쓰지 말고, 감정만 남겨 답합니다.

1. 1화에 들어가면 좋은 상징적 한마디는 무엇입니까?
2. 반복 농담으로 키울 수 있는 말은 있습니까?
3. 쓰지 말아야 할 실제 말투나 표현은 무엇입니까?
4. 마지막 컷에 남기고 싶은 기록자식 한 줄은 어떤 톤입니까?

## 7. 인스타 포스트 정보

1. 1화 제목은 임시로 어떤 방향이면 좋습니까?
2. 캡션은 어떤 톤이면 좋습니까?
   - 짧고 시니컬
   - 담담한 회고
   - 직장인 공감
   - 다음 화 유도
3. 해시태그는 넓은 직장 공감형으로 갈까요, IT 직무 공감형으로 갈까요?
4. 1화에서 댓글을 유도한다면 어떤 질문을 던지고 싶습니까?

## 8. 보류 판단

아래 중 하나라도 예라면 1화 원본은 더 각색하거나 다른 사건으로 바꿉니다.

1. 원본 조직을 아는 사람이 보면 특정될 수 있습니까?
2. 특정 인물의 평판을 낮추는 사실 기록처럼 읽힐 수 있습니까?
3. 고객, 계약, 입찰, 보안, 인사평가, 장애 원인 같은 고위험 정보가 핵심입니까?
4. 원본 사건을 아는 사람만 웃을 수 있습니까?
5. 재미가 특정인의 실수나 약점에 기대고 있습니까?

## 최소 답변 형식

바쁘면 아래 8개만 답해도 1화 초안을 시작할 수 있습니다.

```text
1. 공개 범위:
2. 1화 시작 위치:
3. 핵심 감정:
4. 각색된 한 문장 상황:
5. 등장 역할 2~3개:
6. 1컷 훅:
7. 3컷 폭발 장면:
8. 마지막 컷 톤:
```
