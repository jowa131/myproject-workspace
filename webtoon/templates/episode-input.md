# 첫 에피소드 입력 템플릿

이 템플릿은 공개 가능한 웹툰 기획안을 만들기 위한 입력 양식입니다. 실제 실명, 회사명, 고객명, 프로젝트명, 날짜, 금액, 내부 자료, 비밀정보는 적지 않습니다.

## 1. 안전 확인

- 공개 범위: 비공개 초안 / 내부 공유 후보 / 공개 후보
- 민감도: 낮음 / 중간 / 높음
- 절대 드러내면 안 되는 정보:
  - 인물:
  - 회사/조직:
  - 고객/외부 파트너:
  - 프로젝트/서비스:
  - 날짜/금액/내부 지표:
  - 보안/계약/정책:

## 2. 원본을 각색한 5문장 요약

실제 사실을 그대로 쓰지 말고, 역할과 상황만 남깁니다.

1. 누가 무엇을 원했나요?
2. 어떤 오해나 장애물이 있었나요?
3. 가장 웃기거나 아픈 순간은 무엇인가요?
4. 결과가 어떻게 뒤집혔나요?
5. 독자가 가져갈 한 줄은 무엇인가요?

## 6. 공개 전 자체 점검

- [ ] 실명, 회사명, 고객명, 프로젝트명이 없습니다.
- [ ] 실제 날짜, 금액, 내부 지표, 보안 정보가 없습니다.
- [ ] 실제 인물을 특정할 수 있는 말투, 외형, 경력 조합이 없습니다.
- [ ] 누군가의 평판을 낮추는 구체적 사실처럼 읽히지 않습니다.
- [ ] 비난보다 상황 코미디와 업무 공감이 중심입니다.
- [ ] 공개 후보라면 `docs/anonymization-and-publication-checklist.md`를 통과했습니다.
