# 인스타 4컷 웹툰 제작 준비 목록

이 문서는 100화 규모의 익명화 직장 웹툰을 인스타용 4컷 포스트로 제작하기 위해 필요한 준비 항목을 정리한 것입니다.

## 전제

- 기존 5막 구조는 유지합니다.
- 이전에 만든 1~100화 개별 제목은 확정안이 아니라 교체 가능한 초안으로 봅니다.
- 각 화는 인스타 피드에서 읽기 쉬운 4컷 포스트를 기본 단위로 합니다.
- 플랫폼 이미지 권장 규격은 변할 수 있으므로, 실제 게시 전 Instagram 공식 도움말 또는 업로드 화면에서 최신 규격을 다시 확인합니다.
- 실제 회사명, 고객명, 프로젝트명, 날짜, 금액, 내부 시스템명, 특정 인물 단서는 제작 문서와 공개 후보 파일에 저장하지 않습니다.

## 1. 시리즈 기준

- 시리즈 한 줄 정의
- 5막별 핵심 역할
- 20화 단위 분위기 변화
- 25개 미니 사건 단위 운영 여부
- 제목 확정 기준
- 공개 가능한 소재와 보류 소재 기준
- 회차 번호 체계
- 시즌 1 종료 지점

## 2. 4컷 서사 템플릿

각 화는 아래 네 컷 구조를 기본으로 합니다.

| 컷 | 역할 | 필요한 항목 |
| --- | --- | --- |
| 1컷 | 훅 | 상황, 장소, 등장 역할, 독자가 바로 아는 문제 |
| 2컷 | 꼬임 | 오해, 요청 변경, 말의 생략, 관계 압박 |
| 3컷 | 폭발 | 가장 웃긴 표정, 침묵, 파일명, 메신저, 회의 장면 |
| 4컷 | 반전/기록 | 한 줄 결론, 다음 화 떡밥, 자기풍자, 반복 장치 |

준비할 것:

- 4컷용 대사 길이 기준
- 컷당 말풍선 개수 제한
- 마지막 컷 고정 장치
- 컷 사이 시간 점프 규칙
- 4컷 안에 넣지 않을 설명의 기준
- 긴 사건을 여러 화로 나누는 기준

## 3. 에피소드 입력 항목

각 화마다 최소한 아래 항목을 준비합니다.

- 회차 번호
- 임시 제목
- 소속 막
- 미니 사건 번호
- 원본 감정
- 공개용 핵심 상황
- 익명화 강도
- 등장 역할
- 1컷 대사와 화면
- 2컷 대사와 화면
- 3컷 대사와 화면
- 4컷 대사와 화면
- 반복 장치
- 인스타 캡션 초안
- 해시태그 후보
- 대체 텍스트 후보
- 공개 전 위험 메모
- 상태: 아이디어, 4컷 대본, 콘티, 작화, 검수, 예약, 게시, 보류

## 4. 캐릭터 준비

실제 인물을 캐릭터로 옮기지 않고, 역할형 합성 캐릭터만 사용합니다.

필요한 것:

- 기록자 캐릭터
- 급한 요청자 캐릭터
- 침착한 정리자 캐릭터
- 회의 수호자 캐릭터
- 마감 알림자 캐릭터
- 배경 인물 2~3종
- 캐릭터별 말투 제한
- 캐릭터별 금지 요소
- 표정 8종
- 감정 과장 규칙
- 복장과 소품 기준

주의할 것:

- 실제 인물의 외형, 말투, 직함 조합을 그대로 쓰지 않습니다.
- 특정 회사 조직도처럼 보이는 관계도를 만들지 않습니다.
- 빌런은 개인이 아니라 요청, 일정, 문서, 시스템, 회의, 파일명 같은 장치로 분산합니다.

## 5. 비주얼 시스템

100화를 유지하려면 매번 새로 디자인하지 않아도 되는 규칙이 필요합니다.

준비할 것:

- 4컷 기본 레이아웃
- 말풍선 스타일
- 말풍선 안 텍스트는 가로와 세로 모두 말풍선 중심에 맞추고, 말풍선 선이나 꼬리와 겹치지 않게 충분한 여백을 둡니다.
- 같은 화의 수정본은 하나의 최신 색감 기준 파일에서 이어서 작업하고, 이미지 생성 편집 후에는 동일한 색보정 값을 다시 적용해 컷마다 톤이 달라지지 않게 합니다.
- 대사 수정 시 로컬 활자 합성으로 한 컷의 글자 톤이 다른 컷과 달라지면 최종본으로 쓰지 않습니다. 손글씨 질감은 기존 컷들과 같은 굵기, 흔들림, 간격으로 통일한 뒤 검수합니다.
- 캡션 박스 스타일
- 제목 표기 위치
- 회차 번호 위치
- 색상 팔레트
- 글꼴 후보
- 배경 템플릿
- 회의실, 책상, 복도, 메신저 화면, 문서 화면 같은 반복 배경
- 파일명, 체크리스트, 알림, 메일, 캘린더 같은 반복 소품
- 감정 효과선과 침묵 표현
- 썸네일에서 읽히는 첫 컷 규칙

## 6. 제작 방식 결정

아직 아래 항목을 정해야 합니다.

- 직접 작화, AI 이미지 초안, 카드뉴스형 UI, 혼합 방식 중 선택
- 한 화를 단일 4컷 이미지로 낼지, 캐러셀로 나눌지 결정
- 1화당 제작 시간 목표
- 1주 게시 횟수
- 선작업 배치 크기
- 수정 라운드 횟수
- 원본 아이디어와 공개용 대본을 분리하는 위치
- 최종 이미지 저장 위치
- 공개 후보와 비공개 보류분 저장 위치

## 7. 인스타 게시 준비

게시 전 필요한 것:

- 계정 콘셉트 문장
- 프로필 소개 문구
- 고정 게시물 후보
- 회차별 캡션 톤
- 해시태그 묶음
- 대체 텍스트 작성 규칙
- 게시 주기
- 댓글 대응 기준
- 민감한 반응이 왔을 때 숨김, 수정, 삭제, 보류 기준
- 재게시 또는 묶음 회고 기준
- 성과 기록 항목: 저장, 공유, 댓글 반응, 이탈이 큰 회차

## 8. 안전 점검

각 화마다 공개 전 아래를 확인합니다.

- 실제 회사나 고객을 떠올리게 하는 단서가 없는가
- 특정 인물의 말투, 외형, 직책, 실수가 드러나지 않는가
- 인사, 평가, 계약, 입찰, 보안, 장애 원인처럼 위험한 주제가 사실 기록처럼 읽히지 않는가
- 원본 사건을 아는 사람만 이해하는 농담이 아닌가
- 비난보다 상황 코미디와 자기풍자가 중심인가
- 대사에 내부 용어, 고유 시스템명, 날짜, 금액이 없는가
- 캡션과 해시태그에도 식별 단서가 없는가
- 이미지 안의 파일명, 화면 텍스트, 배경 문서가 안전한가

## 9. 100화 운영 보드

100화를 관리하려면 회차별 제작 상태가 보여야 합니다.

필요한 컬럼:

- 화수
- 막
- 미니 사건
- 임시 제목
- 핵심 감정
- 코미디 장치
- 등장 역할
- 4컷 대본 상태
- 콘티 상태
- 작화 상태
- 안전 점검 상태
- 인스타 캡션 상태
- 게시 상태
- 보류 사유

## 10. 우선순위

바로 다음에 정하면 좋은 순서입니다.

1. 4컷 포스트 기본 레이아웃을 정합니다.
2. 4컷 대본 템플릿을 `templates/`에 추가합니다.
3. 역할형 캐릭터 5~7개를 확정합니다.
4. 25개 미니 사건만 먼저 다시 잡습니다.
5. 1~4화만 4컷 대본으로 시험 작성합니다.
6. 한 화를 실제 인스타용 이미지 초안으로 만들어 제작 시간을 측정합니다.
7. 20화 단위로 안전 점검과 반복 장치 점검을 합니다.
