# 회사 에피소드 웹툰화 워크플로

## 목적

회사에서 겪은 실제 에피소드를 웹툰, 카드뉴스, 짧은 만화형 콘텐츠로 바꿀 때 반복해서 쓰는 제작 기준입니다.

## 기본 원칙

- 실화는 그대로 옮기지 말고, 감정과 구조만 남긴 뒤 인물, 직책, 회사명, 일정, 수치, 장소, 고객 정보 등 식별 단서를 바꿉니다.
- 한 화에는 하나의 사건과 하나의 감정만 둡니다. 예: 억울함, 민망함, 반전, 깨달음, 협업의 어려움.
- 당사자 비난보다 상황 코미디, 업무 시스템, 커뮤니케이션 오해를 중심에 둡니다.
- 공개 전에는 "읽는 사람이 실제 인물을 특정할 수 있는가"를 기준으로 다시 검토합니다.

## 제작 단계

1. 원본 에피소드를 5문장으로 줄입니다.
   - 누가 무엇을 원했는가
   - 어떤 오해나 장애물이 있었는가
   - 가장 웃기거나 아픈 순간은 무엇인가
   - 결과가 어떻게 뒤집혔는가
   - 독자가 가져갈 한 줄은 무엇인가

2. 실명 요소를 각색합니다.
   - 이름은 역할형 별명으로 바꿉니다.
   - 부서, 직급, 거래처, 날짜, 금액, 프로젝트명은 조합해서 새로 만듭니다.
   - 한 사람의 특징을 여러 캐릭터에 나누거나, 여러 사람을 한 캐릭터로 합칩니다.

3. 인스타용 4컷 구조로 만듭니다.
   - 1컷: 평범한 업무 상황과 훅
   - 2컷: 이상한 요청, 오해, 갈등 발생
   - 3컷: 가장 강한 장면 또는 코미디 폭발
   - 4컷: 반전, 기록, 후일담, 다음 화 떡밥

4. 공개 등급을 정합니다.
   - 비공개 메모: 원본 사실 보존 가능
   - 내부 공유: 팀원이 특정되지 않도록 각색 필요
   - 공개 콘텐츠: 회사, 개인, 고객, 프로젝트를 추정할 단서 제거 필요

5. 업로드 전 체크합니다.
   - 특정 개인의 평판을 낮추는 구체적 사실처럼 읽히지 않는가
   - 개인정보나 업무상 비밀이 들어가지 않았는가
   - 당사자가 보면 본인 이야기라고 특정할 수 있는가
   - 회사 정책이나 계약상 공개 금지 내용이 아닌가

## 저장 형식 결정

초기 콘텐츠 저장 형식은 Markdown episode log와 YAML front matter를 함께 쓰는 방식으로 정합니다.

선택 이유:

- 초안 단계에서는 사람이 읽고 고치기 쉬운 Markdown이 가장 빠릅니다.
- YAML front matter는 공개 범위, 상태, 감정, 캐릭터 역할, 안전 점검 같은 구조화된 값을 보관할 수 있습니다.
- 나중에 앱, 사이트, JSON API, 이미지 중심 폴더 구조로 옮겨도 Markdown 파일을 원본 기획 데이터로 삼을 수 있습니다.
- 원본 사건과 공개용 기획안을 한 파일에 섞지 않도록 강제하기 쉽습니다.

기본 폴더:

- `templates/episode-input.md`: 새 에피소드 입력 템플릿
- `episodes/`: 에피소드별 공개용 기획 로그
- `docs/anonymization-and-publication-checklist.md`: 익명화 규칙과 공개 전 체크리스트

파일 이름은 `episodes/YYYY-MM-slug.md`처럼 의미를 남기되, 실제 날짜나 프로젝트명을 그대로 쓰지 않습니다. `YYYY-MM`은 작성 월이나 가상의 시즌 구분으로만 사용하고, 사건 발생일을 뜻하지 않습니다.

## 안전한 톤

- "누가 잘못했다"보다 "일이 이렇게 꼬였다"로 씁니다.
- 상대를 무능하게 그리는 대신, 시스템과 커뮤니케이션 오류를 웃음 포인트로 둡니다.
- 실제 결론이 씁쓸하더라도 마지막 컷은 독자가 공감하거나 배울 수 있는 문장으로 닫습니다.

- 등장 인물 역할:
- 가장 강한 감정:

- 3컷 폭발:

## 확인한 주의 근거

- 개인정보보호위원회 보도자료의 가명정보 제도 설명은 특정 개인이 식별되지 않도록 가명처리하고, 사전 준비, 위험성 검토, 가명처리, 적정성 검토, 안전한 관리 단계를 거치는 흐름을 안내합니다.
  - https://www.pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=C020010000&nttId=11928

  - https://www.law.go.kr/LSW//lsLinkProc.do?efYd=19930413&joNo=030700&lnkJoNo=undefined&lsClsCd=L&lsId=prec19930413&lsNm=%ED%98%95%EB%B2%95&mode=11
