# MyProject Common Development Docs

These documents define reusable working rules for development under
`C:\MyProject`.

- `task-packet-template.md`: minimum task packet for non-trivial work
- `verification-gates.md`: standard verification result levels
- `generated-artifacts.md`: generated/local artifact handling rules
- `ui-content-regression-checklist.md`: browser/content regression checklist
- `yulchive-integration-boundary.md`: ownership boundary for Yulchive feature projects
- `current-target-template.md`: template for separating current operation from target architecture
