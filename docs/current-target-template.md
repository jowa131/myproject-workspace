# Current And Target Template

Use this when a project currently runs differently from its intended long-term
architecture.

```text
Project:
Updated:

Current operation:
- Runtime:
- Data storage:
- Auth/security:
- Deployment:
- Backup/recovery:
- Known manual steps:

Target architecture:
- Runtime:
- Data storage:
- Auth/security:
- Deployment:
- Backup/recovery:
- Automation:

Gap list:
- Required change:
- Risk:
- Verification:
- Owner or next task packet:
```

Keep this distinction in project Wiki pages when local Windows operation,
mock data, temporary credentials, or manual publishing are still in use.
